# Context Pack: Mini Task Tracker Trial

## Goal

Build a minimal local task tracker prototype.

## Idea

A small browser-based task tracker where a user can:

- add tasks
- mark tasks done
- delete tasks
- see pending vs completed counts
- use it entirely in the browser with local state

## Scope

- Simple task entry form
- Pending and completed task counts
- Task list with done and delete actions
- Local browser state only
- Minimal but polished styling

## Non-goals

- No auth
- No database
- No backend persistence
- No deployment
- No collaboration or multi-user support

## Constraints

- Keep it small and usable
- Prototype first
- Prefer plain HTML/CSS/JS unless repo conventions suggest otherwise
- Generate a multi-file project prototype under `projects/mini-task-tracker/app/`
