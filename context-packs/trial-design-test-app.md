# Design Test App

## Goal

- Create a minimal local prototype for a design-test app and verify that Agent Studio can use a UX Designer handoff before Task Planner and Dev.

## Scope

- Produce a project-scoped design handoff under `projects/design-test-app/design/handoff.md`
- Let Task Planner read that handoff and reference it in generated tasks
- Generate a small project-scoped prototype under `projects/design-test-app/app/`

## Constraints

- Local-first only
- Human-reviewed task flow only
- No database
- No auth
- No background jobs

## Out of Scope

- Production deployment
- Penpot integration
- Multi-user collaboration
