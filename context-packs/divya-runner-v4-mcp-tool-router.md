# Context Pack: DIVYA Agent Runner v4 MCP Tool Router

## Goal

Design an efficient MCP/tool-router layer for DIVYA Agent Company.

## Scope

- Let agents access repo files, logs, tasks, state, and external tools through a controlled interface
- Support direct interaction with any agent
- Reduce token waste by routing only relevant context
- Keep file/repo as source of truth

## Features

- Tool router design
- Agent-to-tool access rules
- Context retrieval strategy
- MCP server plan
- Direct agent interaction model

## Non-goals

- No full implementation yet
- No autonomous task execution
- No unrestricted tool access
- No UI yet
- No production deployment

## Constraints

- Efficient context usage
- Human-in-the-loop
- Secure tool access
- Minimal first implementation
