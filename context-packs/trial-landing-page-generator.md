# Context Pack: Landing Page Generator Trial

## Goal

Build a minimal landing page generator prototype.

## Idea

A small local web tool where a user enters:

- product name
- tagline
- 3 to 5 features

The app generates a simple HTML landing page preview.

## Scope

- Simple form
- Generated landing page preview
- Minimal styling
- Local-only prototype

## Non-goals

- No auth
- No database
- No payments
- No deployment
- No AI API integration yet

## Constraints

- Keep it small
- Prototype first
- Prefer plain HTML/CSS/JS unless repo conventions suggest otherwise
