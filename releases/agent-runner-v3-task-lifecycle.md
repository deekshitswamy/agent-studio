# Agent Studio v3 Task Lifecycle

Status: Stable  
Mode: Human-in-the-loop

## Overview

Agent Studio v3 standardizes how tasks are created, validated, executed, and closed.

It builds on:

- v1: execution engine
- v2: task queue
- v2.1: queue validation

v3 ensures that tasks are consistent, verifiable, and safe to execute.
