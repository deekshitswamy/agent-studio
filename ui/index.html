Guided Local Workflow

A local-first operator console for running Task Planner, reviewing drafts, saving task files, starting bounded Dev work, and checking logs one step at a time.

Plain HTML, CSS, and JS only Context pack remains primary input Everything stays human-triggered

Workflow Guide

Recommended Next Step

1. Run Task Planner

Choose task-planner and run it with the current context pack.

2. Review Drafts

Inspect detected Task Planner source and the editable unsaved drafts.

3. Save Task

Save one reviewed draft to tasks/<task-id>.md when it looks right.

4. Run Dev

Use a saved task’s Run Dev button to start one bounded implementation run.

5. View Logs

Reuse the returned logId to inspect plain-text run output and follow-ups.

Start by loading agents and choosing the next human-triggered step.
